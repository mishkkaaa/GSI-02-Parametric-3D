## 3. Тема
Разработка модуля параметрического 3D-моделирования для автоматизированной оценки вариантов застройки (в рамках проекта ГСИ-02).

## 4. План работы на 2 года

### 1-й год обучения (2026–2027 гг.)
**Цель года:** Разработка базового прототипа модуля, настройка интеграции с вычислительным ядром и проведение первых тестов.

*   **Октябрь – Январь:** 
    *   Проектирование и согласование с командой структуры JSON-контракта (координаты, габариты, этажность зданий).
    *   Написание базового скрипта на Python (GhPython) в Grasshopper для парсинга JSON и генерации первичной 3D-геометрии в Rhino.
    *   *Промежуточный результат:* Прототип на конференции ППС.
*   **Февраль – Апрель:**
    *   Реализация автоматического расчета геометрических ТЭП (площадь застройки, суммарная поэтажная площадь).
    *   Настройка автоматической генерации видов (план, аксонометрия) и выгрузки изображений (PNG) / геометрии (GeoJSON).
    *   *Промежуточный результат:* Работающий модуль на конференции КМУ.
*   **Май – Июнь:**
    *   Подготовка к интеграции с Исполнительной моделью (ГСИ-09): приведение форматов данных к единому стандарту.
    *   Апробация модуля на реальных вариантах застройки, предоставленных командой. Оценка скорости генерации и точности расчетов.
    *   *Промежуточный результат:* Доклад на конференции по математическому моделированию, формирование отчета за 1 год.

### 2-й год обучения (2027–2028 гг.)
**Цель года:** Внедрение интеллектуальных методов анализа (VLM), интеграция со смежными модулями и подготовка магистерской диссертации.

*   **Сентябрь – Декабрь:**
    *   Разработка механизма передачи базовой 3D-геометрии и ТЭП в модуль контроля стоимости (ГСИ-07) для расчета план-факта.
    *   Связка модуля с визуально-языковыми моделями (VLM) для автоматического описания сгенерированных 3D-сцен и выявления аномалий.
*   **Январь – Март:**
    *   Тестирование разработанного пайплайна на реальных геодезических данных компании Главстрой СПб.
    *   Оценка экономического и временного эффекта от внедрения модуля (сокращение времени на предпроектный анализ).
    *   Написание научной статьи по результатам исследования.
*   **Апрель – Июнь:**
    *   Финализация архитектуры программного модуля.
    *   Оформление текста магистерской диссертации.
    *   *Итоговый результат:* Защита ВКР (магистерской диссертации).
